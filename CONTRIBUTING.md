# Contribute to the Seedly hub

Open a GitHub issue or pull request for a broken link, documentation correction, or public resource that helps Seedly operators. Link to the affected section, describe what you verified, and include the source for any new information.

To suggest a project for the [Go High Level alternatives guide](guides/go-high-level-alternatives.md), include the upstream repository, license file, and workflow it can replace. Describe how it runs on infrastructure the operator controls, note any paid edition requirements, and disclose your affiliation with the project.

For account or purchase questions, use [Seedly support](mailto:support@goseedly.com). Use synthetic examples in public issues and pull requests. Keep account exports, customer details, license keys, and credentials private.
